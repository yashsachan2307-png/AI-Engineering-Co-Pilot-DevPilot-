# Resume Bullets

These bullets are crafted for technical resumes to highlight the genuine engineering achievements of building DevPilot.

## Option 1: AI & Data Engineering Focus
- Architected and developed a Retrieval-Augmented Generation (RAG) system using Spring Boot, PostgreSQL, and `pgvector` to enable semantic code search and context-aware LLM query responses across entire GitHub repositories.
- Engineered a deterministic Java Abstract Syntax Tree (AST) parsing pipeline to extract structural dependencies and security vulnerabilities, mitigating LLM hallucinations by grounding AI responses in proven code facts.
- Built an autonomous AI Engineering Agent capable of multi-step tool calling, allowing users to query codebase architecture, perform automated code reviews, and generate contextually accurate refactoring proposals.

## Option 2: Full-Stack & Infrastructure Focus
- Designed and built a modular monolith application serving a React (Vite) frontend with a Spring Boot REST API, integrating GitHub OAuth and JWT for secure stateless authentication.
- Implemented asynchronous ingestion pipelines using Spring `@Async` and Server-Sent Events (SSE) to clone, parse, and embed repositories into vector space in the background while providing real-time UI progress updates.
- Configured a lightweight, containerized deployment architecture using Docker and Docker Compose, securely managing environment variables and health-checks for Postgres and Spring Boot without requiring complex orchestration.

## Option 3: Concise Bullets (Pick 2-3)
- Built an AI-powered code analysis tool using React, Spring Boot, and PostgreSQL with `pgvector` for semantic codebase search and RAG workflows.
- Developed a deterministic AST (Abstract Syntax Tree) analyzer to generate accurate dependency graphs and static security findings, grounding LLM outputs to reduce hallucinations.
- Implemented an asynchronous background ingestion engine connected via Server-Sent Events (SSE) to handle GitHub repository cloning, chunking, and embedding generation.
- Designed an autonomous Engineering Agent leveraging function calling to navigate codebases, debug issues, and propose refactoring changes based on retrieved context.
